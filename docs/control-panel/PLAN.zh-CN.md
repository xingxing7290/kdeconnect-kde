1. 构建基线：确认 Android Wrapper/JDK/SDK；准备 Windows Qt/KF/Craft；记录现有构建和测试失败并修复影响开发的基线问题。

3. 桌面主界面：完成左导航、手机预览、按钮编辑/拖入、快捷库、多页/选项、图标与配对入口；截图对照。

5. Android 控制：完成全屏面板、页切换、音量、图标、离线/重连、兼容入口；与真实桌面端执行联调。
6. 智能跟随和表盘：前台进程绑定与切页、空闲计时和唤醒、全部参考表盘类型、城市/文本与真实天气。
7. 完整回归：模型、协议、存储、UI、平台动作、安全边界、真机双端、重启/断网/多页/多设备、视觉对照、长时间运行。
8. 交付：构建 APK 与 Windows 安装/可运行包，实际安装验证；README、测试报告、已知限制、下载路径、构建复现步骤；中文提交推送并核对 SHA。
