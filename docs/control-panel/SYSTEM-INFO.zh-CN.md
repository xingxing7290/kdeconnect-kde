# 电脑状态表盘

本页说明「电脑状态」功能：由 Windows 端采集本机硬件计数器，经 KDE Connect 推送到 Android 平板，在表盘上以数据卡片为主、角落显示时间的方式呈现。

## 1. 设计原则

```
Windows 桌面端（常驻，唯一采集本机硬件）
   └─ PanelSysInfo  · 每 2 秒采样，5 秒心跳，200ms 合并推送
        │  kdeconnect.controlpanel.sysinfo
        ▼
Android 平板 —— 「电脑状态」表盘（只读） + 桌面「电脑状态」设置页
```

- **只读**：只采集聚合数值，不下发路径、机器名、磁盘卷标、进程列表或任何字符串标识。
- **不写配置**：快照是实时状态，与天气/进度/智能家居一样，不进入配置、不改 revision。
- **不编译**：本阶段按用户要求只改源码，未编译运行。

## 2. 显示的数据（核心六项）

| 指标 | 来源 | 表盘显示 |
|---|---|---|
| CPU 使用率 | 两次 `GetSystemTimes` 差值 | `23.5% · 8 核` |
| 内存 | `GlobalMemoryStatusEx` | `50% · 8.0 GB / 16.0 GB` |
| 磁盘（系统盘） | `GetDiskFreeSpaceEx` | `40% · 200 GB / 500 GB` |
| 网络速率 | `GetIfTable2` 累计字节差值 | `12.5 KB/s / 3.1 KB/s`（↓/↑） |
| 运行时间 | `GetTickCount64` | `4d 0h 0m` |
| 进程数 | `CreateToolhelp32Snapshot` | `214` |

- 只看当前值，不做历史趋势（与智能家居功能一致）。
- 采样间隔默认 2 秒，可在 1–30 秒之间调整。

## 3. 使用方法

1. 在桌面控制面板左侧选「表盘选择」，点「电脑状态」按钮（或左侧「电脑状态」页的「配置」）。
2. 勾选「启用电脑状态采集」，选择采样间隔，保存。
3. 在「表盘选择」里选择「电脑状态」表盘；平板上即可看到实时数据。
4. 桌面「电脑状态」页同时显示当前采集结果，便于核对。

## 4. 可靠性

- **心跳**：即使数据无变化，每 5 秒也重发一次快照，让平板区分「没变化」和「断线」。
- **新鲜度**：平板侧 20 秒窗口（心跳的 4 倍），安静的机器不会误报「数据已过期」。
- **降级**：某项指标采集失败时只省略该字段，手机显示 `--`，不把整个表盘打成「连接失败」。
- **兼容**：下发配置时探测平板是否声明支持 `kdeconnect.controlpanel.sysinfo`；旧 APK 不支持时把表盘临时降级为数字时钟，避免整份配置校验失败导致控制面板打不开。

## 5. 隐私与安全

- 桌面私有配置只保存采样开关与间隔，不含任何机器数据。
- 快照通过白名单投影构造，字段固定；协议文档与两端测试共同约束不出现路径/主机名类标识符。
- 无控制指令，只有只读数据；平板无法借该通道修改电脑设置。

## 6. 已知限制

- 当前仅 Windows 采集；其它平台编译通过但指标显示为不可用。
- 网络速率是所有网卡的聚合值，不区分具体网卡。
- 磁盘只取系统盘，不含各分区明细。
- 无历史曲线、无温度/风扇/GPU 指标（首期按范围收窄）。
- 与智能家居一样，桌面界面进程与守护进程各自采集一份（跨进程共享计数器成本过高），不影响数据正确性。
