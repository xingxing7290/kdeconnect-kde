# 控制面板 0.1.0-alpha.1 功能体验版

版本标签：controlpanel-v0.1.0-alpha.1。日期：2026-11-12。

这是个人 fork 的阶段性功能体验版，不是 KDE 官方版本，不表示全部开发或完整测试已经完成。用户要求先输出一个小版本，因此本次只做生成体验包必需的编译、包核验和最小启动检查；后续仍继续补齐全部功能，再统一回归。

## 本版包含什么

- 控制屏：Android 横屏 6 x 3 固定槽位；Windows 手机预览、分类快捷库、按钮编辑与拖放。
- 按钮：程序、快捷方式、文件/文件夹、网站、快捷键、系统功能，以及既有远程命令入口。支持自定义名称、图标、程序参数与工作目录。
- 页面：单页、多页（最多十页）和应用跟随；配置更新保留有效当前页，过期编辑有保护。
- 外观：名称/音量栏开关、背景色、切页方向，两端共享配置。
- 音量：真实音量、静音、输出选择；Windows 统一系统、媒体、通信默认角色，失败尝试回滚，无法完整恢复时明确报错。
- 表盘：原创数字、指针、天气、信息和汽车风格，空闲切换、唤醒、城市和个性文本；天气不可用或过期状态保留。
- 连接：沿用 KDE 配对和加密连接；离线显示缓存并禁用动作，重连不补发离线点击；增加主动重新同步与可读错误反馈。

以上是代码和本版打包范围，不是逐项验收通过表。完整需求及未通过项目仍以 [开发计划](PLAN.zh-CN.md) 为准。

## 下载与使用

- [Android 体验版与源码](https://github.com/xingxing7290/kdeconnect-android/releases/tag/controlpanel-v0.1.0-alpha.1)
- [Windows 对应源码版本](https://github.com/xingxing7290/kdeconnect-kde/releases/tag/controlpanel-v0.1.0-alpha.1)

Android 文件：kdeconnect-controlpanel-0.1.0-alpha.1-android-debug.apk。最低 Android 6.0（API 23）。应用 ID 为 org.kde.kdeconnect_tp.debug，可与官方正式版并存，但会替换相同应用 ID 且签名匹配的旧调试版。APK 内上游版本仍显示 1.37.0-debug；0.1.0-alpha.1 是本 fork 控制面板体验包版本，不冒充上游版本号。使用仓库已有公开调试密钥签名，不是生产签名。

Windows 文件：kdeconnect-controlpanel-0.1.0-alpha.1-win64-internal.zip。本地内部体验包；第三方组件声明及对应源码归档尚未完整收口，因此本次不公开上传这个 Windows 二进制到 GitHub。桌面 GitHub 预发布提供已提交的对应源码和说明，不把源码归档描述为可直接运行的 EXE。

Windows 将整个包解压到 D:/Apps 等本地目录，双击 Start-ControlPanel.cmd，不能只复制 EXE。无需管理员权限，不安装服务、不添加开机启动、不自动修改防火墙。独立数据默认在包旁 profile 目录，详情见包内 README.zh-CN.md。备份与日志不要上传私钥或配对身份。

两端都打开后，进入原 KDE 设备管理，在可信网络配对；Android 对应电脑页打开“控制面板”，Windows 在“桌面控制”中编辑。原官方客户端没有新增面板模块，需要配套本 fork。没有自动向当前华为手机安装。

## 已知限制

- 尚未完成参考图逐项视觉比对、全部按钮/快捷键/lnk、普通局域网发现、多设备长时、横竖屏/无障碍和干净 Windows 环境的完整验收。
- 共享音量后端的三角色切换及失败回滚尚未做实际写入回归；原生操作不是原子事务。设备移除或并发变更可能使回滚不完整，不保证应用已打开的音频流自动迁移。
- ApplicationFrameHost 的子窗口识别是有限兼容策略，不保证全部 UWP/WinUI 或提权窗口；不会自动提权。
- 原 System Volume 网络协议没有逐次写入结果确认；手机显示状态不代表所有失败场景已有完整反馈。
- 历史 Lint 有 477 项错误，本次未重新运行或宣称已清零。Android 编译仍有旧模块资源默认值警告，未扩大范围修复。
- Windows 未签名且只供本地内部体验，未完成第三方发行材料、最终安装/卸载及发布签名；APK 为调试包。不要将此版本用于需要可靠性保证的环境。
