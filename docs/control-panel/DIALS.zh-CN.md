# 空闲表盘与天气

更新：2026-11-12。开发中的个人 fork；不代表完整交付验收。

## 操作与输入规则

电脑“表盘选择”包含推荐、当前表盘和更多表盘。点卡片后确认才保存选择；取消不改变配置。城市与个性化文本一起原子保存，关闭/取消弹窗不提交临时输入。

空闲进入可开关，默认 5000 毫秒，支持 1000..86400000 毫秒。Android 使用单调时钟计时；长按、拖动或持续按键期间不进入表盘。首次唤醒的整次触摸（移动、多点、松手或取消）不送给控制按钮，第二次触摸才能执行。键盘重复与组合键同样不补发。返回操作可先唤醒；退后台暂停，恢复后重新计时。

五类画面使用设备真实本地时间，每秒更新：大字数字钟、椭圆指针、圆钟加天气、浅色信息、原创汽车示意图。汽车图不是车辆状态，不显示伪造车速或传感器数据。当前采用 24 小时制，自定义文本有长度/行数限制和省略处理。

## 天气的数据来源与隐私

天气通过电脑获取并同步给手机。仅在空闲表盘开启且城市非空时自动查询；不读取 GPS，不发送设备 ID、按钮目标、窗口标题或文件路径。城市名发送给 Open-Meteo 的地名查询服务，解析后经纬度用于其天气接口。重名取服务排序首项，画面显示解析后的城市和国家；应使用“Paris, France”等限定名称减少歧义。中文“市”查询无结果时会去掉末尾“市”再查一次。

数据为天气模型的当前条件，不是本地实测传感器。界面显示 Open-Meteo 来源、模型时间和获取时间，温度按整数摄氏度四舍五入。原始快照仍保存小数温度。接口、时间单位和 WMO 编码依据 [天气接口文档](https://open-meteo.com/en/docs) 与 [城市查询文档](https://open-meteo.com/en/docs/geocoding-api)。

免费服务仅供非商业用途，天气数据署名规则遵循其许可；商业发布应另选适用的付费服务或自托管，不应直接沿用免费端点。代码本身仍按原 GPL 许可。详见 [Open-Meteo 条款](https://open-meteo.com/en/terms)。

## 缓存、过期及错误

- 成功获取后按 15 分钟间隔更新，失败约 5 分钟后重试。读取新缓存时按剩余刷新时间安排下一次查询，而不是每次重启重新延长。
- 每一步 HTTP 请求总时限 15 秒、传输空闲超时 10 秒。只访问固定 HTTPS 服务，拒绝重定向，不忽略 TLS 错误。响应最多 64 KiB，手机快照最多 16 KiB。
- 验证单位为摄氏度、Unix 秒，温度有限且在 -100..70，WMO 编码在支持集合中，时间不能明显来自未来。旧模型时刻不能覆盖已有较新数据。
- 请求中/失败/电脑断线时可显示最后有效快照，但明确标为缓存；不改写原模型时间和获取时间。
- 获取超过 2 小时或模型时间超过 3 小时视为过期，温度显示 --°C，不以旧数值冒充当前天气。
- 电脑缓存 weather.json 位于面板配置目录，原子写入；手机缓存为每设备插件偏好中的 panel_weather。离线恢复最多保留一天的已知快照，显示仍受上述新鲜度规则约束。
- 城市改变立即清掉当前画面的旧城市天气。收到的天气必须匹配当前配置 revision 和城市；错误天气不禁用正常按钮或改变动作会话。
- 空城市、关闭、查询中、不可用、过期均有明确状态；不会随机生成温度，也不会伪造更新成功时间。

缓存文件只含天气及城市元数据，不包含配对密钥。备份天气缓存不是恢复按钮配置的必要条件。

## 本地测试与运行环境

用户选择暂不向连接的华为手机安装调试包，本阶段没有安装操作。本地渲染采用 Robolectric 原生图片运行库，截图不等同于真机验收。

本次获准为 Android 单元测试开启正式资源。资源生效后，未指定测试 SDK 的原测试按目标 SDK 37 运行，需要 Java 21；原生图片测试明确使用 SDK 28。Java 21 下测试框架需 --add-opens=java.base/jdk.internal.access=ALL-UNNAMED。该参数仅用于本机构建/测试 JVM，不写入 APK，也不修改其他插件业务行为。

本机入口为 E:/git/kdeconnect-tooling/build-android.ps1。JDK 21 位于 D:/Java/kdeconnect-jdk21，SDK、运行库、Gradle 缓存、临时目录和日志均在 D 盘；下载运行库与 JDK 后已分别核对主仓 SHA-512 和官方 SHA-256。

Windows 普通单测使用模拟 HTTP 响应，不联网取天气；PanelEditor 默认不启用网络，生产 app 和配对插件显式启用。独立 panelweatherintegration <城市> 用于实时接口验证，不注册为普通 CTest。可选 KDECONNECT_WEATHER_LIVE_FIXTURE 只把已经验证的真实快照交给本地渲染测试，不在测试中临时联网，不把测试数据打包进 APK。
