# 阶段十二：先完成全部功能开发，再统一测试

日期：2026-11-12。用户调整执行顺序：先完成参考文档对应的全部功能开发，最后再统一测试。本记录是开发进度，不是测试报告，也不表示完整开发或交付已经完成。

## 当前工作方式

1. 以 REQUIREMENTS.zh-CN.md 为完整需求基线，不因已有代码或容易验证的部分缩减目标。
2. 开发阶段继续逐项核对和补齐两端实现，只做源码审阅、语法/资源结构及差异检查；暂不启动 Gradle/CMake 构建、单测、Lint、UI 回归、模拟器联调或安装。
3. 功能开发清单全部收口后，再统一构建、测试、修复、复测、视觉比对及打包。统一测试仍覆盖原全部验收项，不用历史分散结果代替。
4. GitHub 持续同步中文开发提交，但未测试的开发提交不称为稳定版，不据此重新发布 APK/Windows 包。

最后已验证的历史节点是 Android 1075f53f2（257 项）和桌面 9a3152ab5 对应的 21 个套件。它们不覆盖本阶段代码。历史 Lint 477 项错误也不是本阶段新运行结果；本阶段新增提示文本后，具体数量需在最后统一检查时重新统计。

## 本批实际开发

桌面仅修改控制面板界面与 PanelEditor：

- 快捷库按系统功能、系统设置、常用网站展开/收起，区分默认系统图标；点击添加时，满页给出替换或新增页提示，仍支持原拖放。
- 页签显示序号与名称、长名称省略并可查看完整提示，横向滚动容纳十页，选择页自动进入可视区域；保留悬浮选择。
- 非首页提供逐页删除入口，删除确认绑定明确的页面 ID；仍保留原删除当前页入口和最后一页保护。
- 页面重命名、应用绑定和删除加入页面 ID + revision 的编辑上下文，避免弹窗打开后页面或配置变化导致误改、误删。
- 预览比例、边框、浅色按钮、阴影及蓝色音量轨道对齐参考方向；槽位补充键盘和无障碍编辑入口。
- 页面选项改为可换行布局，增加颜色预览取色入口，保留十六进制输入；单页不显示无意义的切换方向。
- 表盘页右上设置入口统一管理空闲开关、时长、城市和文本，取消不保存；保存前检查配置修订。
- 按钮编辑增加独立恢复默认图标，读取程序图标复用去除外层引号后的路径；文件选择失效时给出提示，不直接读取空对象。
- 页面和参数错误改为可理解的提示，原有未检查版本接口继续保留，供内部流程和已有调用使用。

Android 仅修改控制面板界面、Activity 及该模块中英文资源：

- 面板槽位使用与桌面预览一致的浅色底与边框。
- 已配对设备离线时，“重新同步”复用原有主动刷新入口；不修改 BackgroundService 或 LAN 实现，也不在缓存恢复时自动创建插件。
- 同步、配置变化、权限、程序目标、命令、快捷键等失败给出可读原因与处理建议；保留未知错误的诊断信息。
- 成功和失败都显示动作结果，并使用温和无障碍播报；连接状态独立排版，避免长错误挤走返回或重试按钮。
- 不修改其他插件、配对、执行协议或最低系统版本。
