# 控制面板图标

更新：2026-11-12。开发版功能，完整交付仍以 PLAN 验收清单为准。

## 使用

在电脑控制页点击槽位打开编辑窗口，可选择本地 JPG/PNG，预览后点击保存。取消不会修改按钮或配置修订号。程序按钮保存时若没有自定义图标，会尝试读取本地 exe/lnk 的程序图标；也可使用“读取程序图标”重新提取。其他类型可恢复按类别显示的默认图标。

程序图标提取不会启动程序，也不解析/启动快捷方式目标。只允许本地固定盘或移动盘中的文件，不提取 UNC/网络路径。快捷方式中的绝对本地图标位置优先，否则尝试其本地目标。环境变量图标位置等无法识别的情况显示默认类别图标，可手动上传图片。

上传后会生成新的 256 x 256 PNG，保留长宽比、透明补边，并去除原图片元数据。配置只引用新 PNG 的 SHA-256，不发送原文件路径、原文件名或 EXIF。程序原生图标亦按相同流程规范化。

## 保存与离线

电脑资源位于面板配置目录下的 assets/<hash>.png。备份或迁移面板时，应一起保留 panel.json、已有配置备份和 assets 文件夹。删除按钮不会自动删除对应资源，以免影响配置备份或尚未保存的编辑；资源仓库上限为 128 MiB，满后导入明确失败，不静默删除旧资源。

手机资源位于应用私有 files/control-panel-assets，磁盘上限 128 MiB，内存图片缓存 8 MiB。按内容去重，容量不足时淘汰最旧受管 PNG。已成功缓存的图标在当前面板断线时仍显示，动作禁用；清除应用数据或系统/用户删除资源后需再次联网获取。多个电脑共用手机图标仓库，历史资源可能被淘汰。

手机只请求当前配置实际引用且本地缺失/损坏的资源，逐个接收。图片缺失或传输失败显示类别图标和提示，不因此禁用正常的控制动作；重新同步可再次尝试。实际断线显示和新缓存实例持久化分别有真机、单元测试证据；离线冷启动进入控制页尚未完整验收。

## 限制和协议

- 导入源上限 8 MiB，图片宽高各不超过 4096；仅 PNG/JPEG。
- 规范化 PNG 上限 512 KiB，宽高必须恰为 256，接收时检查 SHA-256、PNG 签名、MIME、边界尺寸和实际解码。
- 程序资源文件上限 256 MiB，快捷方式上限 1 MiB；读取后的目标资源也检查大小。
- 资源 ID 必须为 64 位小写十六进制。网络请求不能指定路径。
- 请求包含 sessionId、revision、assetId；电脑验证会话、配置修订及当前引用，最多每设备每秒 16 次有效资源请求。
- 响应元数据最多 4096 字符；声明大小须与附件大小一致。每设备最多一个接收任务，全局两个图标 IO 工作线程。
- 单项最多尝试两次；等待响应 20 秒，读图标 socket 的单次读取超时 3 秒、读取循环总时限 15 秒。断线/销毁关闭资源，不补发动作。
- 读取超时使用经用户确认的按次 Payload 接口，仅图标模块调用；不修改原文件传输等插件的默认行为。LAN 附件建立连接仍使用上游现有策略，因此上述图标读取时限不代表整个共享传输层都有连接超时。
- 旧修订响应触发重新取配置；未知资源、忙或丢失返回资源错误，不作为动作失败处理。

此机制沿用 KDE Connect 的配对加密通道。更多字段见 [协议](PROTOCOL.zh-CN.md)，本阶段证据见 MILESTONE-05.zh-CN.md。
