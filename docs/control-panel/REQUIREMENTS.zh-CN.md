# KDE 控制台需求与参考分析

状态：需求基线，尚未实现。更新：2026-10-28。

## 依据与目标

参考：[妙控桌面v1~3](https://my.feishu.cn/docx/THaodCAb4oKzxpxOJgMc7Ja6nds)。已读取 127 个有序文档块并逐张查看功能章节的原图。文档标注 Android 4.0.1、桌面安装包 4.0.5，教程截图包含 1.0.3 和 2.0.1。以教程明确展示的外观和行为为当前需求；不能据此声称已经验证 4.x 安装包行为。

在用户自己的 KDE Connect Android 和 desktop fork 上开发，交付可配对、可配置、可执行的两端软件。桌面端面向 Windows，保留上游跨平台构建结构。Android 手机/平板作为控制屏。沿用 KDE Connect 加密连接、配对及其他设备功能。

## 参考视觉结构

- 桌面窗口：浅灰侧栏、浅白主画布、蓝色选中/确认状态、常规窗口标题栏。
- 左导航：表盘选择、桌面控制、开启连接、关于；早期截图中的显示设置在新版合并到控制页底部。
- 控制页：居中的横屏手机预览，黑色粗圆角边框和柔和阴影，内部白色或自定义背景；右侧快捷操作分类。
- 面板：6 列 x 3 行，18 个固定槽位。空槽显示灰色加号；按钮为圆角浅色方块，应用图标居中，名称可隐藏或在底部单行省略。
- 音量：面板右侧竖向滑杆，上方扬声器、下方静音入口；可整体隐藏。
- 页码：预览下方显示当前页、删除 x 和新增 +；多页面支持悬浮切页。
- 底部设置：页面模式、音量控制开关、名称显示开关、背景颜色取色器及十六进制输入、多页面切换方向。
- 弹窗：居中浅色表单、半透明遮罩、取消与蓝色确认按钮。
- 表盘：两列宽幅圆角预览卡；精选推荐、当前表盘、更多表盘；设置齿轮位于右上。
- Android 控制界面应与桌面预览共享布局、图标、名称、背景、当前页和音量选项；主要使用横屏全屏，适配手机长宽比、刘海和系统手势区域。

| --- | --- | --- |
| UI-01 | 整体导航与控制页 | 桌面四个主要入口可操作；控制面板保持参考图的左右区域及 6 x 3 网格；Android 显示对应控制页。 |
| BTN-01 | 固定槽位 | 空格、新增、修改、删除、拖动换位均保留槽位语义；空位不会压缩导致其他按钮移位。 |
| BTN-02 | 外部拖入 | 从资源管理器拖入文件夹、exe、lnk，创建按钮并识别名称/图标。 |
| BTN-03 | 自定义程序 | exe/lnk 文件选择，默认名称和程序图标，可改名和上传图片；手机点击后电脑打开目标。 |

| PAGE-02 | 多页面 | 至少 1 页、最多 10 页；新增、删除、页码悬浮选择；手机按设置方向滑动；删除当前页后落到有效页。 |
| PAGE-03 | 智能跟随 | 识别前台可执行程序，显示可复制的名称，绑定页面；切到对应程序时手机自动切页；未知程序回到首页。 |
| PAGE-04 | 跟随稳定性 | 编辑器自身、弹窗和瞬时窗口不会导致持续抖动；手动切页和自动跟随的优先级明确。 |
| OPT-01 | 外观选项 | 音量栏、名称显示、背景色、上下/左右切换方向保存后同步；重启保持。 |
| VOL-01 | 实时音量 | 手机和电脑可更改默认输出设备音量及静音，并收到真实状态；默认输出设备切换后继续可用。 |
| DIAL-01 | 表盘选择 | 画廊、当前预览、确认弹窗；选择后 Android 显示一致表盘；使用自行绘制组件。 |
| DIAL-02 | 表盘类型 | 覆盖图中数字大字时钟、模拟指针、模拟钟+天气、信息/电子墨水风格，以及旧截图的汽车视觉类展示；具体资源由原创图形实现。 |
| DIAL-03 | 空闲自动进入 | 可开关；时长单位毫秒，参考默认 5000；操作后重新计时；触摸退出时不误触执行底层按钮。 |
| DIAL-04 | 参数与实时数据 | 城市及个性化文本可填可保存；日期时间实时变化；天气显示真实数据、更新时间及不可用/过期状态。 |
| CONN-01 | 连接与授权 | 电脑管理设备及配对，Android 选择电脑并连接；未配对设备不能读取私有面板或触发动作。 |
| CONN-02 | 同步与恢复 | 修改按钮/页面/表盘/选项后已连接手机更新；断线显示离线并禁止执行；重连取最新完整配置，不补发离线点击。 |
| COMPAT-01 | KDE 功能保留 | 原远程命令、输出与停止、键鼠、音量、文件分享等入口保留；未升级另一端时给出可理解提示。 |
| DEL-01 | 可交付 | Android APK 和 Windows 可运行包/安装包、中文 README、安装/配对/操作/排障说明、版本及测试报告。 |
| GIT-01 | 仓库同步 | 用户两端 fork、本地源码、中文提交；每个里程碑 push 并核对远端 SHA；不向 KDE 上游提交 MR。 |

## 关键状态规则

1. 设备未配对 -> 配对等待 -> 已配对离线 -> 连接中 -> 配置同步 -> 可控制。失败必须可见且能重试。
2. 默认模式显示首页；多页面选择保持在合法范围；跟随模式以应用匹配页或首页为目标。
3. 空闲表盘与按钮面板是同一个控制会话的两种显示状态；退出表盘的首次触摸只负责唤醒。
4. 电脑是配置权威端。Android 只发按钮 ID、页选择或音量请求，不发送可执行路径和任意命令。
5. 每次执行具有请求 ID；超时/失败/重复请求有明确结果。配置修订号不同的过期按钮请求不能误执行新按钮。
6. 删除、重排和切换模式都不能静默丢失其他页面或图标。
